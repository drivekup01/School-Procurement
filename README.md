# School-Procurement

เริ่มโครงการใหม่จากศูนย์ (13 ตุลาคม 2569)

ลบไฟล์ระบบเดิมทั้งหมดออกจากสาขา main แล้ว ยังไม่มีการสร้างระบบใหม่


## รายการพัสดุร่วม หน้า 4 / 6 / 11

`shared-procurement-items.js` ใช้รายการชุดเดียวและวัดพื้นที่ A4 จริงเพื่อเพิ่มหน้าต่อใน Preview โดยคงหน้าเอกสารหลัก 1–11 ไว้เดิม แก้เฉพาะรูปแบบแต่ละหน้าในตัวแสดงผล ไฟล์ Word เพิ่มแถวจริง ใช้หัวตารางซ้ำและปล่อยข้อความยาวไหลต่อหน้า โดยไม่เปลี่ยนตัวแบ่งหน้าเอกสารเดิม โปรแกรม Word อาจแบ่งหน้าต่างจาก Preview ตามฟอนต์และเครื่องพิมพ์

ข้อมูลร่วมเก็บใน `sharedItemsV2` ภายในพื้นที่เก็บหน้า 4 เดิม จึงบันทึก/เปิดเอกสารเก่าได้โดยไม่เปลี่ยนรูปแบบไฟล์งานหรือเซิร์ฟเวอร์ นำข้อมูลเก่าจากทั้งสามหน้ามารวมครั้งแรกโดยเก็บค่าดั้งเดิมไว้ รายการที่ชื่อ/จำนวน/ราคาต่างกันไม่ถูกรวมทับ ควรตรวจรายการจากเอกสารเก่าก่อนพิมพ์

ทดสอบด้วย `node tests/shared-procurement-items.cjs` (ต้องมี Playwright และ JSZip; กำหนด CODEX_NODE_MODULES ได้) ครอบคลุม 36 รายการ ข้อความยาวเกินหน้า หน้าต่อ การเชื่อมแก้ไข ยอดรวม XML ทั้งสามตาราง บันทึก/เปิดกลับ และนำข้อมูลเก่าเข้า


## ชื่อบุคลากร

`personnel-options.js` เก็บรายชื่อ 24 คนจาก Sheet1 ช่วง B4:C27 ของไฟล์รายชื่อบุคลากรใน repository (รวมคำนำหน้าชื่อและนามสกุล ตัดเฉพาะช่องว่างส่วนเกิน) ใช้กับตัวแปร assigned_officer_name, chief_officer_signer_name, officer_signer_name และ inspector_name ทุกหน้า ชื่อที่มีอยู่ในเอกสารเก่าและไม่ตรงกับบัญชีปัจจุบันจะแสดงเป็นตัวเลือกชื่อเดิมจนกว่าผู้ใช้จะเลือกเปลี่ยน ไม่เปลี่ยนชื่อผู้ขาย/ผู้รับจ้าง เมื่อปรับรายชื่อใน Excel ต้องปรับชุดข้อมูลในไฟล์นี้และเพิ่มเลขเวอร์ชันที่ document-bootstrap.js ด้วย
