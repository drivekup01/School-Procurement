# School Procurement — Online Preview

เว็บทดลองระบบจัดซื้อจัดจ้างโรงเรียน (GitHub Pages)

## สถานะ
- หน้าภาพรวม โครงการ งานจัดซื้อ ประวัติแก้ไข ยอดเงินแยกฝ่าย
- ข้อมูลเก็บใน localStorage บนเบราว์เซอร์และ origin นี้ **เท่านั้น**
- **ยังไม่ได้เชื่อม Firebase**, ไม่มีการล็อกอินจริง, ไม่มีการบังคับสิทธิ์รายฝ่ายจริง
- **ห้ามกรอกข้อมูลราชการหรือข้อมูลส่วนตัวจริง**
- ยังไม่ได้สร้างเอกสาร Word หรือเก็บไฟล์หลักฐานออนไลน์

## เปิดใช้งาน GitHub Pages
Repository > Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save

URL หลังเปิดใช้งาน: https://drivekup01.github.io/School-Procurement/

## การพัฒนาถัดไป
ใช้โค้ด V0.3 ต้นฉบับใน ZIP สำหรับการย้ายระบบขึ้น Firebase ที่มีการยืนยันตัวตนจริงและกฎสิทธิ์ก่อนรับข้อมูลจริง เว็บนี้เป็น preview เบื้องต้นแยกต่างหาก ไม่ใช่ระบบใช้งานจริง
