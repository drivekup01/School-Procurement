# Google Docs form — วิธีติดตั้ง

ระบบนี้เป็นเว็บแอป Apps Script แยกจาก GitHub Pages เพื่อเข้าถึง Google Docs อย่างถูกต้อง ไม่ต้องเผย API key

## ติดตั้ง
1. เปิด https://script.google.com/home/projects/create ด้วย Google Account ที่เข้าถึงเอกสารต้นฉบับได้
2. นำ `Code.gs` ในโฟลเดอร์นี้ไปแทนโค้ดเริ่มต้นของ Apps Script
3. กด **+** > **HTML** ตั้งชื่อ `Index` แล้วนำเนื้อหา `Index.html` ไปใส่
4. กด Save จากนั้น **Deploy** > **New deployment** > ประเภท **Web app**
5. ตั้ง **Execute as: User accessing the web app** และ **Who has access: เฉพาะคนที่ต้องการอนุญาตจริง ๆ** (เช่นบัญชีในองค์กร หากตัวเลือกนี้ใช้ได้)
6. Authorize สิทธิ์ Google Docs / Drive ตามหน้าจอ แล้วเปิด URL ลงท้าย `/exec`

## วิธีใช้
- ระบบอ่านพารามิเตอร์ `{{key}}` จาก Google Docs ต้นฉบับและสร้างฟอร์ม
- กรอกข้อมูลแล้วกด **บันทึกและดูตัวอย่าง**
- สร้างสำเนาใหม่แทนค่าพารามิเตอร์ และแสดง Preview
- สำเนาก่อนหน้าที่ระบบสร้างจะถูกย้ายไป Trash เมื่อบันทึกครั้งถัดไป
- ต้นฉบับไม่เปลี่ยน และข้อมูลแต่ละบัญชีแยกกันโดย UserProperties
- ดาวน์โหลดเป็น Word ผ่านเมนู File > Download > Microsoft Word (.docx) ใน Google Docs

## ข้อจำกัดที่ต้องรับทราบ
- นี่คือ **อัปเดตหลังคลิกบันทึก** ไม่ใช่อัปเดตทุกครั้งที่กดแป้นพิมพ์
- Google Docs Preview อาจ cache แสดงเอกสารช้ากว่าการบันทึกเล็กน้อย
- ต้องมีสิทธิ์อ่าน/สร้างสำเนาจากเอกสารต้นฉบับ
- อย่าเลือกการ Deploy แบบ **Execute as me + Anyone** เพราะจะให้ผู้เยี่ยมชมเรียกการสร้างสำเนาโดยใช้สิทธิ์เจ้าของ
- ปัจจุบันไฟล์ Google Docs ต้นฉบับมีสิทธิ์ **Anyone with the link: Editor** ควรจำกัดสิทธิ์ก่อนใช้งานจริง เพื่อป้องกันคนอื่นแก้แม่แบบ
