# เปิดใช้การบันทึก Google Drive

เก็บข้อมูลในโฟลเดอร์ school-budget ที่กำหนดไว้ โดยใช้หน้าเว็บเดียวกับ School-Procurement

1. เปิด https://script.google.com/ แล้วสร้างโปรเจกต์ใหม่
2. คัดลอกไฟล์ Code.gs ในโฟลเดอร์นี้ไปแทนโค้ดเริ่มต้น
3. เปิด Project Settings แล้วเลือกให้แสดง appsscript.json จากนั้นคัดลอกไฟล์ appsscript.json ไปแทน
4. เลือก Deploy > New deployment > Web app
5. ตั้ง Execute as เป็น Me และ Who has access เป็น Anyone ตามขอบเขตที่ต้องการในรอบนี้
6. กด Deploy และอนุญาตบัญชีที่เข้าถึงโฟลเดอร์ school-budget ได้
7. เปิดลิงก์ Web app ที่ลงท้าย /exec เพื่อใช้ปุ่มบันทึกข้อมูลและเปิดเอกสารเดิม

หน้าเว็บแสดงปุ่มบันทึกและประวัติการบันทึกเอกสาร ชื่อเอกสารสร้างจากเลขที่หนังสือและรายละเอียดจัดซื้อหรือชื่อโครงการโดยอัตโนมัติ

แต่ละครั้งที่บันทึกสร้างไฟล์ JSON ชุดใหม่เพื่อเก็บประวัติ เมื่อกดชื่อเอกสารจะดาวน์โหลดไฟล์ข้อมูลและให้เลือกโหลดค่ากลับมาแก้ไขบนเว็บ

เว็บ GitHub เดิมเก็บประวัติไว้ในเบราว์เซอร์เครื่องนั้น เว็บ Apps Script เก็บในโฟลเดอร์ Drive ที่กำหนด หนึ่งชุดเก็บข้อมูลทุกหน้า รวมตัวเลือกหน้า 3 ตารางหน้า 4/6/11 และค่าคำนวณอัตโนมัติ

ระบบไม่เปลี่ยนสิทธิ์แชร์ของโฟลเดอร์และไม่มีคำสั่งลบไฟล์ ผู้ที่มีลิงก์เว็บ Apps Script แบบ Anyone สามารถเปิดชุดเอกสารที่ระบบบันทึกในโฟลเดอร์นี้ได้
